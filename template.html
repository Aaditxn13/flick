flick

An agent skill that animates UI icons from a sentence. Describe how the icon should move; your SVG stays exactly as it is and only motion is added.

01Install

One command

$npx skills add __REPO__

Adds one folder: the skill's instructions and a small checking script. No dependencies; Node 18+ runs the checks. If your agent was already open, start a new session so it picks the skill up.

02Add your idea

Say which icon, and how it should move

›/flick <your idea>

Paste your SVG in the same message or point at the file. No SVG yet? Name the icon and it draws a simple one first, then animates it. You can also just ask in plain words, like "animate this icon so it…"; the skill picks it up on its own.

You get bell.animated.svg next to your file, plus one line on how to trigger it from your app.

03How it works

A plan, not a redraw

  1. Reads your SVG and numbers its shapes. The file itself is never edited.
  2. Turns your idea into a motion plan: which shapes move, the style, the pivot point, timing and trigger.
  3. A script applies the plan and checks every shape against your original. If anything would change, it refuses and the plan gets fixed, not your icon.
  4. Hands you the animated SVG with a one-line spec and the class or data-state your app toggles to play it.

06Your SVG stays yours

No new paths. No edited paths. Checked every time.

The agent never writes your SVG. It writes a motion plan, and a script applies it with a short list of allowed edits, then compares every shape with your original before saving.

It can add

  • one <style> block
  • class names on your existing shapes
  • a bare <g> around a shape that already has a transform
  • pathLength="1" for line drawing
  • aria-hidden and data-state on the root

It refuses

  • new or removed shapes, edited path data or coordinates
  • changed colors, stroke widths or viewBox
  • masks, filters, url(), morphing via CSS d
  • CSS that reaches outside the icon
  • anything that changes the icon at rest

Asking for something that needs new shapes, like sparkles or play morphing into pause, gets the closest motion that keeps your drawing, with a note saying what was left out.

07CLI

Use the engine directly

The skill runs these for you. They live in the installed skill folder.

# list the shapes, by index
node scripts/icon-motion.mjs inspect bell.svg
# apply a motion plan → bell.animated.svg
node scripts/icon-motion.mjs apply bell.svg bell.motion.json
# did any drawing change?
node scripts/icon-motion.mjs verify bell.svg bell.animated.svg
